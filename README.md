# Digital Hope — Rural Village School Computer Lab Hardware Donation Campaign

A responsive NGO-style landing page for the **Digital Hope** rural school computer lab hardware donation campaign, built strictly with **HTML5 and CSS3** (no JavaScript, frameworks, or backend services).

## Live Website
- **GitHub Pages:** https://yash29codes-ui.github.io/Digital-hope-donation-/

## Project Structure
- `index.html` — Complete semantic HTML5 landing page (navigation, hero, impact stats, mission, school wishlists, donation pledge form, 4-stage refurbishment tracker, classroom gallery, and footer).
- `style.css` — Responsive CSS3 layout, typography, WCAG-compliant focus and contrast styling, mobile CSS-only navigation toggle, and `:target` demo acknowledgement.

## Features
- **Hero & Mission:** Explains the rural digital education divide and how retired working devices empower village school labs.
- **School Wishlist Cards:** Displays student enrollment, working PCs, and required laptops, desktops, and projectors for three sample rural schools.
- **Hardware Donation Pledge Form:** Pure HTML5 form with Device Type (`Laptop`, `Desktop`, `Tablet`), Brand, RAM, Processor, Quantity, Condition, and browser-native constraint validation.
- **Refurbishment Tracker:** Four transparent stages — *Pledge Received*, *Courier Pickup*, *Diagnostic & OS Install*, and *Delivered to School*.
- **Classroom Photo Gallery:** Responsive photo showcase highlighting students learning.
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile viewports.

## Scope & Limitations
- Strictly frontend **HTML5 and CSS3** — the pledge form validates inputs in the browser and shows a CSS `:target` demo confirmation without transmitting or storing data on a server.
- School profiles, enrollment counts, and tracker status are illustrative demonstration data.
- Typography (Google Fonts) and classroom photography (Unsplash) load over HTTPS and require an internet connection.
